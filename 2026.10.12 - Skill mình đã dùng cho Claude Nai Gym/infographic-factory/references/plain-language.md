# Ngôn ngữ dễ hiểu — bỏ viết tắt và thuật ngữ khó

Người xem lướt reel trong 3 giây. Một chữ viết tắt không hiểu = vuốt qua. Quy tắc:

1. Trên **slide**: không để viết tắt chuyên môn đứng một mình. Viết bằng tiếng Việt đời thường, hoặc thêm lời giải thích ngay cạnh (vd "EPA, DHA — 2 dạng omega-3 chính").
2. Thuật ngữ tiếng Anh quen thuộc trong phòng gym (rep, squat, deadlift, cardio, pump) được giữ. Thuật ngữ lạ (Sagittal, tempo, pre-workout, lateral squat…) → đổi sang tiếng Việt.
3. Đơn vị viết thường, đầy đủ: "3–6 mg mỗi kg cân nặng", không "3-6 MG/KG".
4. Không viết tắt từ thường: "VD" → "Ví dụ", "HLV" → "huấn luyện viên", "ĐH" → "Đại học".
5. Caption cũng áp dụng; riêng hashtag thì tự do.

`render_infographic.py` tự cảnh báo khi gặp các chữ viết hoa liền nhau 2–8 ký tự (trừ NAIGYM, PT, VS, OK). Gặp cảnh báo → sửa theo bảng dưới.

## Bảng thay thế đã dùng

| Viết tắt / thuật ngữ | Viết trên slide |
|---|---|
| RPE | tự chấm mức gắng sức 1–10 (10 = hết sức) |
| RIR | số rep còn dư |
| DOMS | đau nhức cơ sau tập (24–72 giờ) |
| TEF | ăn cũng đốt calo / năng lượng tiêu hao để tiêu hoá |
| GI (cao / thấp) | carb hấp thu nhanh / carb hấp thu chậm |
| 1RM | mức tạ tối đa bạn nâng được 1 lần |
| HIIT | cardio cường độ cao ngắt quãng |
| FITT-VP | 6 yếu tố: tần suất, cường độ, thời gian, loại bài, khối lượng, tiến triển |
| PAR-Q+ | bảng hỏi sức khoẻ trước khi tập |
| InBody | đo thành phần cơ thể (tỷ lệ cơ, mỡ) |
| FMS | test 7 động tác cơ bản |
| BDNF | một loại protein nuôi dưỡng não |
| H+ / pH | cơ tăng độ axit |
| Lactate | axit lactic |
| carnosine | (bỏ) → "giúp cơ chống lại độ axit" |
| Sagittal / Frontal / Transverse | tiến – lùi / sang ngang / xoay vặn |
| Central Governor | "não giữ phanh" |
| tempo | nhịp tập |
| pre-workout | đồ uống trước tập |
| lateral squat | squat bước ngang |
| EPA / DHA | giữ (in trên nhãn sản phẩm) + giải thích "2 dạng omega-3 chính" |
| SMART | giữ, nhưng mỗi chữ cái phải có nghĩa tiếng Việt đi kèm |

Gặp thuật ngữ mới → thêm vào bảng này và vào `GLOSSARY` trong script để lần sau tự gợi ý.
